# Commercial use

Official Chikn, Roostr, and FarmLand visual assets classified as `CHIKN-COMMUNITY-NONCOMMERCIAL` are hosted for community non-commercial use under the Chikn team's existing community permission. This repository does not grant commercial permission for those entries.

Before commercially distributing, monetizing, advertising, or using the protected visual assets in a commercial service, obtain a separate written agreement from the Chikn rights-holder through the contact recorded in [`COMMERCIAL_USE.md`](https://github.com/Roost2D/chikn-game-assets/blob/main/COMMERCIAL_USE.md).

That restriction does not apply to Apache-2.0 engine/runtime code, documentation, manifests, rig definitions, animation timing metadata, or the specifically classified `water_swim_ring_coq.png` project artwork. A commercial game may use those systems and project art with independently licensed replacement character/FarmLand art without inheriting the Chikn content restriction.
